# Bybit Trading Bot & Mission Control

Automated quantitative trading bot for Bybit BTC/USDT Perpetual with FastAPI web dashboard and real-time Telegram alerts.

## Features
- Strategy 1 (Liquidity Sweep & Multi-Timeframe FSM)
- Dynamic Risk Schedule & Position Sizing
- 24h & 20-trade Demo Qualification Gate before Live execution
- Web-based API Key & Telegram Vault
- Real-time Market Radar & Heartbeat

## Deployment
Compatible with Docker, Back4app Containers, Render, and Fly.io.
